1. How Java Works

The big picture

Most languages compile directly to machine code for one specific computer. Java takes a different approach: it compiles to bytecode — a universal format that no real CPU understands natively.

The JVM (Java Virtual Machine) sits between your bytecode and the hardware. It reads the bytecode and executes it on whatever machine it's running on — Windows, Mac, Linux, doesn't matter.

This is what "Write Once, Run Anywhere" means. You compile once, and the JVM handles the rest.

The flow: .java file → javac compiler → .class bytecode → JVM runs it

Dissecting main

Every Java program needs a main method — it's the entry point the JVM looks for when it starts your program.

Let's break the signature down word by word:

  • public — the JVM can call it from outside the class
  • static — no object needed to call it
  • void — it doesn't return a value
  • main — the exact name the JVM looks for
  • String[] args — command-line arguments (ignore for now)
The class name must match the filename exactly, including capitalization. HelloWorld.java must contain class HelloWorld.

2. Variables & Primitive Types

What is a variable?

A variable is a named box that holds a value. In Java, every variable has a type that says what kind of value it can hold — and that type never changes.

The 4 primitive types you'll use most:

Type Stores Example
int Whole numbers 42
double Decimal numbers 3.14
boolean true / false true
char Single character 'A'
String is not a primitive — it's a class. But it's used so often it behaves like one.

3. Working with Strings

Concatenation & escape characters

You can join strings together with +. When you mix a String with a number, Java automatically converts the number to a String.

Some characters need an escape sequence because they'd confuse the compiler:

  • \n — newline
  • \t — tab
  • \" — a literal quote mark
  • \\ — a literal backslash
Common mistake: "5" + 3 gives "53", not 8. If one side is a String, + concatenates instead of adding.
